# Meta-Questioning

## On the Productive Expansion and Constraint of Frames

**Model type:** Application Model  
**Scope:** Meta-questioning, frame expansion, recursive inquiry, uncertainty, and stopping conditions for reflective analysis  
**Status:** Exploratory Note  
**Version:** v0.1  
**Last updated:** 2026-07-24

---

# Abstract

Questions operate within frames.

They contain assumptions about what matters, what can be ignored, which relationships are relevant, and where the boundaries of the problem lie.

This creates a fundamental limitation:

A question can be answered correctly within the wrong frame.

Meta-questioning addresses this problem by turning attention from the object of inquiry toward the frame through which that object is understood.

But meta-questioning introduces a second problem.

Every frame can itself be questioned.

The assumptions behind the frame can be questioned.

The criteria used to evaluate those assumptions can also be questioned.

Meta-questioning is therefore theoretically recursive without limit.

More reflection is not automatically better reflection.

A useful method of meta-questioning requires both:

- a rule for expanding the frame
- a rule for stopping that expansion

This note proposes the principle of **Minimum Sufficient Meta-Scope**:

> **Expand the frame as far as necessary, but constrain it as much as possible.**

The purpose of meta-questioning is not maximum abstraction.

It is sufficient depth.

---

# I. The Problem of the Frame

Every question operates inside a frame.

The frame determines:

- what is treated as relevant
- what is treated as external
- which assumptions remain implicit
- which causes are considered
- which uncertainties are visible
- which possible answers can emerge

This means that error can occur at two different levels.

The reasoning inside a frame can be wrong.

But the frame itself can also be inadequate.

A person may therefore reason correctly and still reach a poor understanding because relevant information lies outside the chosen frame.

The problem is not necessarily the answer.

The problem may be the space within which the answer was searched for.

This creates the need for meta-questioning.

---

# II. What Is a Meta-Question?

An object-level question examines something within an existing frame.

For example:

> **Why did this project fail?**

A meta-question examines the frame within which that question is being answered.

For example:

> **Which assumptions about project failure are determining what causes we are currently considering?**

Meta-questioning can therefore expose:

- hidden assumptions
- missing perspectives
- inappropriate boundaries
- irrelevant constraints
- omitted causes
- incorrect criteria

The distinction can be expressed simply:

> **Object-level questioning investigates the object.**

> **Meta-questioning investigates the frame through which the object is being investigated.**
